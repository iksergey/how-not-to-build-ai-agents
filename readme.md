# Как не надо создавать ИИ-агентов

Код к докладу в Школе 21. Один и тот же агент на четырёх языках: цикл агента написан руками,
а вокруг него четыре точки, где стоит ваш код. В каждой папке есть сценарии на шесть косяков
из доклада, они запускаются локально с моделью в Ollama.
